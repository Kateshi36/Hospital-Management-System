Hospital logo files
===================

logo.png  - the logo picture shown on the login screen and in the main window header.
            A square PNG with a transparent background looks best (at least 256 x 256).
app.ico   - the same logo as a Windows icon (title bar, taskbar and the .exe file).

Both are copied next to the .exe when you build. If a file is missing the app still runs and
simply shows the text-only look. To change the logo, replace the files and rebuild.
